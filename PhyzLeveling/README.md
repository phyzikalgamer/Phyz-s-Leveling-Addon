# Phyz Leveling Addon 0.2.0

Direct fork of installed RestedXP Guides v4.11.36, with a classic WoW theme.
Uses RestedXP's own guide window, step engine, map pins and waypoint arrow.
No OpenXP Smart Start, card, terrain routing or custom 21-60 routes are loaded.
Forever's bundled leveling routes cover the early levels (roughly 1-20/22),
plus other bundled guides. A complete Forever 1-60 pack is not included.

Enable Phyz Leveling Addon; disable OpenXP and RestedXP Guides because global
frames and guide APIs remain shared. Right-click the guide header to select a
guide. /phyz and /phyzleveling open the original settings. Select WoW Classic
for the native font, opaque dark panels and Blizzard borders. Custom settings
can still be adjusted. The classic guide window is the default; V2 is optional.

PHYZ2* saved variables start fresh so neither old Phyz nor RestedXP settings and
progress are overwritten. Old OpenXP-based Phyz files are backed up separately.
PhyzEngine is private, so Shortest Path's RestedXP adapter does not automatically
take over this fork's pathing. Shortest Path remains a separate installed addon;
stop any existing journey in its UI if it is still active. Keep TomTom off to
use the original RestedXP arrow. No Shortest Path settings are changed.

Restart WoW after installing this replacement. No in-game validation has been
performed. See NOTICE.md and LICENSE for upstream attribution and licensing.
